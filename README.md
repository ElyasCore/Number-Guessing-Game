Number Guessing Game

A simple Java console game where the program generates a random number between 1 and 100 and asks the user to guess it.

The project focuses on loops, random number generation, conditional feedback, and tracking the number of attempts until the correct number is found.

Features
Generate a random number between 1 and 100
Allow the user to enter guesses
Tell the user whether the guess is too high or too low
Continue until the correct number is guessed
Track the total number of attempts
Display the number of attempts after winning
Concepts Practiced

Scanner · Math.random() · while Loop · Variables · if/else · Counters · Comparisons · break · Random Number Generation

Built as part of my Java learning journey to practice loops, conditions, counters, and generating random values in an interactive program.
